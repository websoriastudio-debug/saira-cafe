# SAIRA Café & Bakery

El repositorio ya tiene un flujo de GitHub Actions que **descomprime y publica automáticamente** el sitio al cargar `saira-cafe-github-pages.zip`.

## Pasos pendientes

1. Descarga el ZIP de ChatGPT: `saira-cafe-github-pages.zip`.
2. En la página principal del repositorio, haz clic en **Add file → Upload files**, arrastra el ZIP **sin descomprimir** y pulsa **Commit changes** en `main`.
3. En **Settings → Pages → Build and deployment**, cambia **Source** a **GitHub Actions**.
4. La acción `Publicar SAIRA Cafe en GitHub Pages` publicará el contenido en https://websoriastudio-debug.github.io/saira-cafe/

Si la acción falló antes de activar Pages, ve a **Actions → Publicar SAIRA Cafe en GitHub Pages → Re-run all jobs**.

> Comprueba con el negocio los datos de contacto y legales antes de utilizar la página comercialmente.
